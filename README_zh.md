# 🤖 Anthropic Agent Methodology | 智能体构建方法论

*从架构决策到生产部署，系统化掌握 AI Agent 构建全流程。*

基于 Anthropic 核心实践指南提炼的全栈方法论，覆盖架构模式选择（Workflow vs Agent）、领域技能注入、多智能体编排与生产级评估体系。帮助开发者在复杂、可扩展的智能体系统中做出正确决策。

---

### ✨ 核心亮点

-   **🏗️ 架构决策框架**：Workflow 与 Agent 的精确划分标准，配合 6 种可组合模式的灵活运用。
-   **🧠 技能驱动演进**：通过渐进式信息加载机制，将领域专业知识注入通用 Agent 中。
-   **🔗 多智能体编排**：Lead-Subagent 架构实现并行执行，突破单模型推理瓶颈。
-   **✅ 生产级评测**：LLM-as-a-Judge 评估方法，结合人工审计的端状态管理策略。

---

### 🚀 快速开始

想要为一个新的 AI 项目选择合适的智能体架构，只需在对话框中输入：

> **"请启用 Anthropic Agent Methodology 技能。我正在设计一个[描述你的具体场景，如：文档处理与数据分析的智能客服系统]，帮我分析应该采用 Workflow 还是 Agent 架构，并给出方案建议。"**
